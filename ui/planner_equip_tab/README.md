# ui/planner_equip_tab/ — Pestaña Planificador de Equipo

## Qué es
Comparativa de equipos y recomendaciones de compra: el usuario evalúa si un equipo que está pensando le conviene más que otro, según sus métricas y su presupuesto.

## Estado actual
- Carpeta sin código (placeholder en `ui/main_window.py`).

## Qué hacer aquí
- Comparar equipos por **datos fríos comparables** (apertura, focal, resolución, bits, refrigeración, precio/presupuesto) — nunca por métricas impuestas: las métricas las define el usuario.
- Mostrar las imágenes adjuntas (diagramas de spot, etc.) **para que el usuario las compare visualmente**; el programa NO analiza ni compara esas imágenes.
- Presentar recomendaciones con explicación de por qué un equipo es mejor para su caso.
